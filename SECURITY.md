# Security Policy

We take the security of ParkoSpace seriously. If you believe you have found a security vulnerability, we appreciate your help in reporting it to us in a responsible manner.

## Supported Versions

Currently, the production environment is supported with security updates:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities. Instead, report them privately using the following process:

1. **Email us directly**: Send a detailed report to [services@parkospace.xyz](mailto:services@parkospace.xyz).
2. **Include details**: Provide a description of the issue, steps to reproduce, potential impact, and any proof-of-concept scripts or screenshots.
3. **Response time**: You can expect an initial response within 48 hours acknowledging receipt of your report.
4. **Resolution status**: We will keep you updated on the progress towards fixing the reported issue.
5. **Responsible disclosure**: We request that you do not disclose the vulnerability publicly or to third parties until we have had a reasonable amount of time to address and resolve the issue.

Thank you for helping keep ParkoSpace secure!
